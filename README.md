# 🌱 KrishiJeevan - AI Powered Crop Recommendation System

## Overview

KrishiJeevan is an AI-powered agricultural assistant that helps farmers make better farming decisions using real-time environmental data and artificial intelligence.

The system integrates weather information, camera-based crop analysis, and OpenAI-powered recommendations to provide personalized crop suggestions and farming guidance.

## Features

* 🤖 AI-powered crop recommendations using OpenAI API
* 📷 Camera integration for crop and field image analysis
* 🌦 Real-time weather-based recommendations
* 🌱 Smart farming assistance and insights
* 📱 User-friendly web interface
* ⚡ Instant AI-generated agricultural guidance

## How It Works

1. The user captures an image of the field or crop using the camera.
2. The system gathers current weather information.
3. Crop and environmental data are analyzed.
4. OpenAI API processes the information and generates intelligent recommendations.
5. The user receives suitable crop suggestions and farming advice.
